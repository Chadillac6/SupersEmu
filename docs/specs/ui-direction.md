# UI direction (draft)

Visual styling is now defined by `brand.md` (light and dark appearance with brick red); it supersedes the dark/cinematic default below.

Status: **Draft, being shaped with Chad in a side chat.** Not final. Record his answers here before M1 UI work.

- Feel: a premium game shelf, not an emulator frontend. Large cover art, dark and cinematic by
  default, no emulator jargon (no "core", "BIOS", "libretro" outside Advanced/Diagnostics).
- Areas: Home (Continue Playing, Recently Added, Favorites, Downloaded), Library (filters by
  system, genre, downloaded, in progress), Game details (Play is the main action, Continue, save
  history, download, disc picker), Player (pause menu, clear save status), Profile (history,
  devices, downloads, server connection), Admin (Mac mini only: server status, import, review
  queue, users, permissions, tokens, logs).
- The server controls which games each user can see. Each user controls their own favourites,
  downloads and progress.
- Platforms: Mac sidebar + menu-bar server status; iPad sidebar in landscape; iPhone bottom tabs and
  horizontal shelves, controller-first with touch controls available.

Open questions for Chad: bright vs dark brand; Home opens on Continue Playing or Recently Added;
system-first or one unified catalogue; closest reference (Plex, Netflix, Apple TV, Steam Big Picture).
